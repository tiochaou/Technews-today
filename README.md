# 🌐 TechNews Today — Portal de Tecnologia

Projeto de portal de notícias moderno construído apenas com HTML5 e CSS3 puro, aplicando conceitos modernos de estilização e responsividade.

📌 Sobre o Projeto

O TechNews Today é um mini portal de notícias focado no universo tech. O objetivo principal do projeto foi estilizar uma estrutura HTML sem alterar nenhuma tag, utilizando recursos modernos do CSS3 para criar uma interface atraente, responsiva e performática.

✨ Recursos & Funcionalidades

Glassmorphism: Cabeçalho fixo com efeito de vidro fosco (backdrop-filter).

Gradiente em Texto: Título principal e botões estilizados com degradês modernos.

Layout com CSS Grid: Organização de conteúdo limpa e flexível.

Header Sticky: Navegação sempre visível no topo da página.

Design Responsivo: Adaptado para telas de celulares e desktops utilizando Media Queries.

Sem Frameworks: Feito 100% com CSS Puro e sem JavaScript.
